INTEGRANTE 01 · PÁGINAS 2 A 4

Ryan — Fundamentos da Web

Tríade · execução · APIs

O FATEC ID combina as três tecnologias da Web. O HTML organiza os elementos, o CSS define a aparência e o JavaScript controla o comportamento. O navegador executa o JavaScript no lado do cliente e oferece APIs prontas para interagir com a página.

Mostre na aplicação: adicione uma tarefa, altere o tema e observe a interface responder sem recarregar a página. Isso demonstra a interação entre estrutura, estilo e comportamento no navegador.
HTML · estrutura
<form id="taskForm">
  <input id="taskName" type="text" required>
  <button type="submit">Adicionar tarefa</button>
</form>
<ul id="taskList"></ul>
CSS · apresentação
.task-form {
  display: flex;
  gap: 12px;
  padding: 16px;
  border-radius: 14px;
}
JavaScript · comportamento e API do DOM
const taskList = document.querySelector("#taskList");

function mostrarAviso() {
  taskList.textContent = "A interface foi atualizada!";
}

Explique: API significa uma interface que oferece recursos prontos. document.querySelector() é um recurso da API DOM do navegador. O JavaScript roda no navegador (client-side); não é necessário enviar cada clique ao servidor.

INTEGRANTE 02 · PÁGINAS 5 E 6

Amanda — Integração e carregamento

Scripts · async · defer

O projeto mantém HTML, CSS e JavaScript em arquivos separados. O arquivo JavaScript é incluído com defer, assim o navegador pode baixar o script enquanto interpreta o HTML e executá-lo depois que o documento for processado.

Mostre na aplicação: abra a página e use o formulário. Explique que a lógica está no arquivo app.js, enquanto o visual está em style.css.
HTML · inclusão usada neste projeto
<link rel="stylesheet" href="style.css">
<script src="app.js" defer></script>
Comparação · padrão, async e defer
<!-- Padrão: pode bloquear o parsing do HTML -->
<script src="arquivo.js"></script>

<!-- async: executa assim que baixar; ordem não garantida -->
<script src="arquivo.js" async></script>

<!-- defer: executa após o parsing, mantendo a ordem -->
<script src="app.js" defer></script>

Explique: defer é adequado aqui porque o JavaScript precisa localizar elementos que já estão descritos no HTML. async é mais indicado para scripts independentes, cuja ordem de execução não seja importante.

INTEGRANTE 03 · PÁGINAS 7 E 8

Breno — Variáveis e lógica

const · let · === · operadores

O sistema usa const para referências que não serão reatribuídas e let quando o valor precisa mudar. Também utiliza igualdade estrita e operadores lógicos para filtrar e validar tarefas.

Mostre na aplicação: escreva parte do nome de uma tarefa na busca e alterne o filtro entre Todas, Pendentes e Concluídas. A lista muda conforme as condições definidas no JavaScript.
JavaScript · variáveis
const taskName = document.querySelector("#taskName");
const statusFilter = document.querySelector("#statusFilter");

let tasks = [];

tasks = [...tasks, { title: taskName.value }];
JavaScript · igualdade e operadores lógicos
const isCompleted = task.completed === true;
const matchesStatus =
  statusFilter.value === "todas" ||
  (statusFilter.value === "concluida" && isCompleted) ||
  (statusFilter.value === "pendente" && !isCompleted);

Explique: === compara valor e tipo. && significa E, || significa OU e ! significa NÃO. const impede reatribuir a variável; let permite atribuir outro valor.

INTEGRANTE 04 · PÁGINAS 9 E 10

Marcos — Funções e DOM

function · arrow · DOM

As funções organizam tarefas do programa em blocos reutilizáveis. O DOM representa o HTML como uma árvore de objetos que o JavaScript pode consultar e modificar em tempo real.

Mostre na aplicação: adicione ou conclua uma tarefa. O resumo de progresso e a lista são atualizados sem editar o arquivo HTML e sem recarregar a página.
JavaScript · declaração e arrow function
function contarConcluidas(lista) {
  return lista.filter((task) => task.completed).length;
}

const atualizarResumo = () => {
  progressText.textContent = "Progresso atualizado";
};
JavaScript · manipulação do DOM
const progressText = document.querySelector("#progressText");

progressText.textContent = "Tarefas concluídas: 2";

// textContent insere texto; innerHTML interpreta marcação HTML.
progressText.textContent = "Você está evoluindo!";

Explique: a função tradicional é declarada com function; a Arrow Function usa =>. O DOM é a ponte entre JavaScript e HTML. textContent insere texto sem interpretar tags HTML, sendo uma opção segura para conteúdo digitado pelo usuário.

INTEGRANTE 05 · PÁGINAS 11 A 13

Lari — Elementos, atributos e eventos

createElement · atributos · eventos

Quando uma tarefa é adicionada, o JavaScript cria elementos HTML, define seu conteúdo e os insere na lista. Os botões de concluir e excluir respondem a eventos. A interface também pode ler e alterar atributos dos elementos.

Mostre na aplicação: adicione uma tarefa, marque-a como concluída e depois exclua-a. Acompanhe como os elementos aparecem e desaparecem na lista.
JavaScript · selecionar, criar e inserir
const taskList = document.querySelector("#taskList");
const item = document.createElement("li");

item.textContent = "Estudar DOM";
taskList.appendChild(item);
JavaScript · atributos
button.setAttribute("aria-label", "Concluir tarefa");
const label = button.getAttribute("aria-label");
const exists = button.hasAttribute("aria-label");
button.removeAttribute("title");
JavaScript · eventos
taskForm.addEventListener("submit", (event) => {
  event.preventDefault();
  // validar os dados e adicionar a tarefa
});

taskList.addEventListener("click", (event) => {
  // identificar o botão acionado
});

Explique: querySelector seleciona; createElement cria; appendChild insere. Os métodos de atributo consultam, definem, verificam e removem atributos. addEventListener escuta eventos como click, input, submit e change.

INTEGRANTE 06 · PÁGINAS 14 A 16

Bruno — Persistência e boas práticas

localStorage · validação · referências

As tarefas são salvas no localStorage para permanecerem disponíveis quando a página for fechada e aberta novamente no mesmo navegador. O projeto também utiliza trim, preventDefault, reset e atualização de classes para organizar o código e a interface.

Mostre na aplicação: adicione uma tarefa, atualize a página e observe que ela continua na lista. Depois altere o tema e veja que a preferência também é mantida.
JavaScript · localStorage
function salvarTarefas() {
  localStorage.setItem("fatecid-tasks", JSON.stringify(tasks));
}

function carregarTarefas() {
  const saved = localStorage.getItem("fatecid-tasks");
  return saved ? JSON.parse(saved) : [];
}
JavaScript · validação e boas práticas
taskForm.addEventListener("submit", (event) => {
  event.preventDefault();

  const title = taskName.value.trim();
  if (title === "") return;

  // adicionar a tarefa...
  taskForm.reset();
});

Explique: localStorage guarda strings; por isso usamos JSON.stringify() para salvar arrays/objetos e JSON.parse() para recuperá-los. trim() remove espaços nas extremidades, preventDefault() impede o envio tradicional do formulário e reset() limpa os campos.
